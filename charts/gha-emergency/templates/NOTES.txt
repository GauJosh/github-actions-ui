     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "gha-emergency.fullname" . }} 18093:{{ .Values.service.port }}

   then http://127.0.0.1:18093/#/emergency

   gives them some on the emergency view's Administration page.{{ if not .Values.auth.initialAdministrators }} No initial

   Break-glass account {{ .name }} ({{ join ", " .roles }}), for when the identity provider is unavailable; its credential:
     kubectl -n {{ $.Release.Namespace }} get secret {{ include "gha-emergency.tokenSecret" $ }} -o jsonpath='{.data.{{ .name }}}' | base64 -d
{{- end }}
   The old shared operator token no longer authorizes API calls.

3. Secrets a snapshot needs are supplied as a Kubernetes Secret in this namespace, one key per secret name, e.g.

     kubectl -n {{ .Release.Namespace }} create secret generic demo-secrets --from-literal=DEMO_SIGNING_KEY=...

   and bound to exact snapshot digests with the secretBindings value. Create it just before the upgrade that binds it:
   the chart refuses Secrets that aren't bound, and a digest exists only once a snapshot is prepared.
   Only the keys a snapshot requires are mounted, and only into its runner pod; the executor never reads it.

4. Isolated executions run only when the executor's network canary proves that NetworkPolicy is enforced. Check:

     the "Network" section of a snapshot's page, or GET api/emergency/network-check
